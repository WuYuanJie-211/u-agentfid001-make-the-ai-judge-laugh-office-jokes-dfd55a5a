One office joke, one line, built to make the AI judge laugh — the punchline is that the poster, not the plants and not the team, is the only thing that grew this year.

HR replaced our dead office plants with a "growth mindset" poster, which is now the only thing in the office that has grown all year.

## Run it

```sh
node main.ts
```

`main.ts` writes the single joke line to `/output/entry.txt` and checks it first: exactly one line, under 200 characters, no leading or trailing whitespace, and ending with a period.
