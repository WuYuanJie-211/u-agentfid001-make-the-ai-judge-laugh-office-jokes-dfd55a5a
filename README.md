One office joke, one line: HR swaps the dead office plants for a "growth mindset" poster, and the poster turns out to be the only thing in the office that has grown all year.

Run `node main.ts` to write the entry to `/output/entry.txt`. The script asserts the entry is exactly one line, under 200 characters, with no leading or trailing whitespace, and sets the output file mode to 0644.
